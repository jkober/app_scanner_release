Chrome, Edge y Opera

Chromium

Puente de conexión para Google Chrome, Microsoft Edge, Opera y Brave. Requiere habilitar políticas una sola vez en la computadora.

Paso 1 • Solo 1ª vez en la PC

Descarga y ejecuta el activador de políticas para autorizar la instalación directa:

💾 Descargar Activador Windows (.reg)
¿Usas Linux? Descargar instalador (.sh)
Paso 2 • Instalación

Haz clic desde Chrome, Edge u Opera y confirma «Agregar extensión»:

✚ Instalar Extensión (.CRX)
✓ Se actualizará automáticamente en segundo plano.
Nota Edge/Opera: Si se descarga el archivo en vez de abrir el diálogo, haz clic en él para confirmar o arrástralo a edge://extensions.
¿Deseas remover la extensión o sus políticas de Chromium?
Desinstalador Windows (.reg) • Desinstalador Linux (.sh)

Mozilla Firefox

1 Clic • Sin Registro

Instalación oficial directa sin tocar el Registro de Windows ni necesitar permisos de Administrador.

Pulsa el botón desde Firefox para abrir el diálogo oficial del navegador:

🦊 + Instalar Extensión en Firefox (.XPI)
✓ Firefox abrirá la ventana: «¿Añadir "RCivil Scanner Bridge" a Firefox?» → Pulsa Añadir.
✓ Autoactualizable silenciosamente vía firefox_updates.json.
💡 Ventaja Firefox: No requiere descargar ni ejecutar ningún archivo .reg previo.
